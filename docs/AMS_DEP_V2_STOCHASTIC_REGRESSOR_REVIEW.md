# AMS-DEP V2 stochastic-regressor / fixed-design bootstrap review

## Status

**LITERATURE AND DESIGN-RISK REVIEW — NOT METHOD RATIFICATION**

The conditional V2 review identified a specific transfer issue:

The AMS-DEP predictor is a lagged return. It is stochastic and generated by the
same return process that generates the target. The current engineering DWB
holds the realized design matrix fixed while bootstrapping null-imposed
residuals.

This document reviews whether that approximation has precedent and what remains
unproven for this project.

No calibration, holdout or BTC/ETH empirical execution is authorized here.

## Relevant literature found

### Gonçalves and Kilian (2004)

- "Bootstrapping autoregressions with conditional heteroskedasticity of
  unknown form"
- Journal of Econometrics 123(1), 89–120
- DOI: `10.1016/j.jeconom.2003.10.030`

This is directly relevant because autoregressions contain stochastic lagged
dependent variables as regressors and the paper studies bootstrap inference
under conditional heteroskedasticity.

Project implication:
fixed-design / wild-bootstrap ideas are not restricted to truly deterministic
economic regressors.

Limit:
this is not the same as AMS-DEP's exact-time dependent-wild-bootstrap
construction, segmented covariance geometry or 7/4/2 joint restriction family.

### Godfrey (2011)

- "Robust Non-nested Testing for Ordinary Least Squares Regression when Some
  of the Regressors are Lagged Dependent Variables"
- Oxford Bulletin of Economics and Statistics 73(5), 651–668
- DOI: `10.1111/j.1468-0084.2010.00630.x`

This explicitly treats OLS regressions containing lagged dependent variables
and emphasizes robust testing when autocorrelation/heteroskedasticity are
present.

Project implication:
the mere presence of lagged dependent variables does not make bootstrap/robust
regression inference conceptually invalid.

Limit:
the hypothesis structure and bootstrap method differ from AMS-DEP.

### Hafner and Herwartz (2009)

- "Testing for linear vector autoregressive dynamics under multivariate
  generalized autoregressive heteroskedasticity"
- Statistica Neerlandica 63(3), 294–323
- DOI: `10.1111/j.1467-9574.2009.00424.x`

The abstract describes a **fixed-design wild bootstrap** for parameter
restrictions in VAR models that is robust to conditionally heteroskedastic
errors.

Project implication:
fixed-design wild-bootstrap inference has direct precedent in dynamic models
with stochastic lagged variables.

Limit:
again, this is not Shao's exact dependent multiplier construction, and it does
not resolve continuity segmentation or exact-time multiplier covariance.

### Brüggemann, Jentsch and Trenkler (2016)

- "Inference in VARs with conditional heteroskedasticity of unknown form"
- Journal of Econometrics 191(1), 69–85
- DOI: `10.1016/j.jeconom.2015.10.004`

This work develops asymptotically valid inference and bootstrap procedures for
stable VARs under conditional heteroskedasticity.

Project implication:
dynamic stochastic regressors plus heteroskedasticity are a standard bootstrap
inference problem, not an exotic exception.

### Predictive-regression literature

Financial predictive regressions have a separate finite-sample literature
because persistent stochastic regressors can create bias and spurious
significance.

Ferson, Sarkissian and Simin (2003),
"Spurious Regressions in Financial Economics?" (DOI
`10.1111/1540-6261.00571`), explicitly studies persistent lagged regressors
and finite-sample distortions.

Project implication:
conditioning on a realized regressor path does not remove all finite-sample
risk. The calibration suite must remain the decisive release gate.

## What this resolves

The conditional-review caveat should be narrowed from:

> fixed-X bootstrap has no precedent with stochastic lagged regressors

to:

> fixed-design/wild-bootstrap inference has substantial precedent in
> autoregressive and VAR models with stochastic lagged variables, but the
> exact AMS-DEP DWB transfer still requires empirical synthetic calibration
> and independent ratification of its precise design choices.

That is a meaningful improvement.

## What this does NOT resolve

No recovered source proves that the following exact combination is
asymptotically valid as implemented:

- 14-column AMS-DEP design;
- lagged return predictor;
- year and state interactions;
- null-imposed restricted residuals;
- segment-centered residuals;
- Gaussian Parzen dependent multipliers;
- exact integer-hour distance;
- independent multiplier processes across declared continuity segments;
- segment-specific `ell=max(2,n_s^(1/5))`;
- same Parzen studentization for observed and bootstrap Wald statistics;
- 7/4/2 joint restrictions;
- six-slot Holm family;
- irregular/asynchronous row masks.

Therefore formula precedent cannot substitute for the frozen Monte Carlo
calibration.

## Research-integrity interpretation

The project's synthetic calibration is especially important because it can
directly test whether the fixed-X approximation produces calibrated p-values
for the exact DGPs the project cares about.

If the frozen V2 calibration fails:
- do not reinterpret the literature as overriding the failure;
- do not retune the DWB within V2;
- do not use the holdout to rescue the method;
- create V3 if the method changes.

If it passes:
- that supports engineering release for the tested synthetic environments;
- it still does not prove universal asymptotic validity;
- full endogenous AMS-V1 pipeline integrity and separate empirical approval
  remain required.

## Reviewer-facing conclusion

The stochastic-regressor caveat is no longer a reason by itself to reject
fixed-design DWB engineering.

It remains a reason to require:
1. exact prospective specification;
2. retained hard null DGPs;
3. new heavy-tail / volatility-break / irregular / asynchronous stresses;
4. calibration followed by unopened holdout;
5. no empirical market-data access before those gates pass.

Current project authorization is unchanged.
