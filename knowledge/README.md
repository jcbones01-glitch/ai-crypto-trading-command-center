# Knowledge Base — AI Trading Learning System

This folder stores what the system has learned, so knowledge survives across sessions and across different AI assistants. Any assistant working on this repository should **read this folder first**.

## Roles
- **Owner:** the repository owner. Authorizes or rejects every build, change, spend or trading action.
- **Creator:** the AI assistant (Claude). Researches, proposes and builds **only what the owner authorizes**, and records what it learns here.

## Standing rules (until the owner changes them)
1. **Paper trading only.** No real money, leverage, derivatives or borrowed money unless the owner explicitly authorizes it in writing.
2. **The owner is a beginner.** Explain everything in plain language.
3. **Evidence first.** Every factual claim links to a source. Opinions are labeled as opinions.
4. **Flag scams.** Warn about anything promising guaranteed returns or asking for deposits. See [03_scam_checklist.md](03_scam_checklist.md).
5. **Don't trust a single backtest.** Any strategy must pass forward paper trading before real money is even discussed.
6. **Privacy.** This repository is public. Never store the owner's personal information here.
7. **Propose, then build.** The creator proposes; the owner authorizes; then the creator builds. Every decision is recorded in [06_decisions_log.md](06_decisions_log.md).

## Owner situation (non-identifying)
- A beginner, interested in using AI to help trade.
- No trading capital for about the next 12 months. Future capital will come from job income.
- Current phase: **learning plus paper trading.**
